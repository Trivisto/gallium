Features

Every converter website, but on your PC

Your files never leave your computer, and there are no size limits or waiting in line.

Right-click to convert

Right-click any file in File Explorer, choose "Convert to", and pick from every format it can become.

Tons of formats

Images, video, audio, documents and more. Gallium detects the file and shows only the formats that make sense.

100% offline

Nothing gets uploaded. No accounts, no file size limits, no waiting in a queue on someone's website.

Install

Up and running in a minute

Three steps. No account needed.

Download

Click Download for Windows above. You'll get Gallium-Setup.exe.

Run the installer

Open it and click through the setup — pick a folder or keep the default. Gallium opens when it's done.

Convert

Drop a file into Gallium, or right-click any file and choose Convert to. Pick a format and where to save it.

If Windows shows "Windows protected your PC", click More info then Run anyway. That appears for new apps from independent developers that aren't code-signed yet.
FAQ

Questions

Is Gallium free?

Yes, completely free, with no ads, account or watermark.

Are my files uploaded anywhere?

No. Everything is converted on your own PC, so it works offline and your files stay private.

Where's the right-click option on Windows 11?

Right-click a file, choose Show more options, then Convert to.

Does it work on Mac?

Right now Gallium is Windows 10 and 11 only.
